## 🌟 RESUMEN EJECUTIVO

El proyecto "Boda Digital" es una plataforma web integral para la gestión de bodas que combina una landing pública interactiva con un panel de administración completo. El sistema está construido con tecnologías modernas y vanilla web, con integración a Supabase para backend y almacenamiento.

## 🗄️ BASE DE DATOS (SUPABASE)

### Esquema de Tablas (11 tablas)

| Tabla | Propósito | Columnas clave |
|-------|-----------|----------------|
| `boda_config` | Configuración general de la boda | novia_nombre, novio_nombre, fecha_boda, cuentas_bancarias (JSONB), dress_code_colors (JSONB), galeria_fotos (JSONB) |
| `invitados` | Gestión de invitados y RSVP | nombre_completo, grupo, pases_adultos, estado_rsvp, mesa_asignada |
| `presupuesto` | Control financiero | categoria, concepto, costo_estimado, costo_real, estado_pago |
| `cotizaciones` | Proveedores y cotizaciones | proveedor, categoria, monto_cotizado, estado |
| `actividades` | Cronograma de tareas | titulo, fase, fecha_limite, completada |
| `compras` | Lista de compras | articulo, categoria, cantidad, comprado |
| `itinerario` | Programa del día | hora, actividad, lugar, orden |
| `dedicatorias` | Mensajes de invitados | autor, mensaje, cancion_sugerida |
| `album_fotos` | Fotos del álbum compartido | autor_nombre, foto_url, aprobada |
| `album_chat` | Chat en vivo del álbum | autor_nombre, mensaje |

### Seguridad RLS
- ✅ Todas las tablas tienen RLS habilitado
- ✅ Políticas de acceso público configuradas para desarrollo

### Triggers Automáticos
- `updated_at`: Actualización automática en todas las tablas
- `validar_estado_rsvp`: Validación de estados de confirmación
- `contar_pases_confirmados`: Cálculo automático de pases

## 🔌 CONEXIÓN A SUPABASE

### Configuración

El sistema utiliza un cliente Supabase con dos modos de operación:

1. Modo Online: Conexión real a Supabase con autenticación
2. Modo Offline/Demo: Persistencia local con localStorage

### Variables de Entorno Requeridas

`env
# Supabase
SUPABASE_URL=https://tu-proyecto.supabase.co
SUPABASE_ANON_KEY=tu-anon-key-public
SUPABASE_SERVICE_ROLE_KEY=tu-service-role-key

# URLs
APP_URL=https://tu-dominio.vercel.app
ADMIN_EMAIL=novios@email.com

# Email (para notificaciones)
RESEND_API_KEY=tu-api-key-de-resend
EMAIL_FROM=no-reply@tudominio.com
`

### Métodos del Cliente Supabase

`javascript
class SupabaseClient {
    // Configuración
    getConfiguracion()
    updateConfiguracion(data)
    
    // Invitados
    getInvitados()
    createInvitado(data)
    updateInvitado(id, data)
    deleteInvitado(id)
    submitRSVP(data)
    
    // Finanzas
    getPresupuesto()
    createPresupuesto(data)
    updatePresupuesto(id, data)
    deletePresupuesto(id)
    
    // Cotizaciones
    getCotizaciones()
    createCotizacion(data)
    updateCotizacion(id, data)
    deleteCotizacion(id)
    
    // Actividades
    getActividades()
    createActividad(data)
    updateActividad(id, data)
    deleteActividad(id)
    
    // Compras
    getCompras()
    createCompra(data)
    updateCompra(id, data)
    deleteCompra(id)
    
    // Itinerario
    getItinerario()
    createItinerario(data)
    updateItinerario(id, data)
    deleteItinerario(id)
    
    // Álbum
    getAlbumFotos(aprobadas)
    uploadFoto(file, metadata)
    approveFoto(id)
    deleteFoto(id)
    getAlbumChat()
    sendChatMessage(data)
    
    // Dedicatorias
    getDedicatorias()
    createDedicatoria(data)
    deleteDedicatoria(id)
}
`

### Persistencia Local (Fallback)

- Todas las operaciones tienen fallback a localStorage
- Claves de almacenamiento: `boda_config`, `boda_invitados`, `boda_presupuesto`, etc.
- Datos de demostración precargados para pruebas inmediatas

`
